# Public Website Visual Refresh

## Goal
Refresh the public-facing 74hrs website with the editorial, modern, boxed feel of OMEX while keeping the existing 74hrs identity, video opening, content, and black/silver/white palette.

## Changes
- Establish a more distinctive condensed display typeface for large headings and a clean supporting typeface for body copy.
- Replace soft glassy styling with sharper dark panels, fine silver borders, compact labels, oversized typography, and structured box grids.
- Restyle the shared navigation, section headings, buttons, cards, dividers, and footer so every public page feels consistent.
- Apply the system to the homepage, shop, GFX/VFX portfolios, booking, queue, VIP library, orders, partners, and legal pages without changing their business logic.
- Preserve the current video opening and 74hrs content; the reference guides the visual language only.
- Keep layouts usable on phones and desktops, with restrained motion and reduced-motion support.

## Technical details
- Define reusable typography, surfaces, borders, spacing, and motion through semantic tokens and shared utility classes.
- Update public shared components first, then page-specific cards and shells.
- Do not restyle admin or customer dashboard interiors except where they inherit the global base styles.
- Verify the main page plus representative shop, portfolio, queue, booking, and VIP views at desktop and mobile sizes.
